- Run in the test sandbox VM (docs/sandbox.md of the workspace), plans written by game start (as few starts as possible).
- Three runs: public 0.9.3 (3 starts), beta 0.9.3 (1 start), follow-up for the card fix (2 starts).
- The VM crashed once (graphics driver of the shared GPU) in an earlier attempt; nothing of it counted.
